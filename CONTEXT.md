# GAIA Solver

A single ReAct agent that answers GAIA benchmark questions, submits its answers to a scoring server, and presents its worklog and benchmark results.

## Language

**Agent**:
The single ReAct-loop agent (reasoning → tool use → observation) that solves questions. One agent instance per question.
_Avoid_: workflow, pipeline, model, assistant

**Task**:
A GAIA benchmark item identified by a task_id, containing a Question, a difficulty Level, and optionally an Attachment.
_Avoid_: problem, item

**Level**:
The difficulty tier of a Task (1–3), as reported by the scoring server.
_Avoid_: difficulty, grade

**Question**:
The natural-language prompt the Agent must answer; part of a Task.
_Avoid_: query, prompt, request

**Attachment**:
The file associated with a Task (image, audio, PDF, Excel, DOCX, PPTX, ZIP, or text), or a video referenced by the Question.
_Avoid_: file, asset, document

**Worklog**:
The step-by-step trace of an Agent's run — its reasoning steps, tool calls, and observations.
_Avoid_: log, transcript

**Run**:
One execution of the Agent over the full set of Questions.
_Avoid_: session, iteration

**Answer bundle**:
The committed artifact, keyed by task_id, that the Space submits answers from — each entry carries a Task's final answer and its Worklog. Generated by local Runs.
_Avoid_: cache, cache file, answers file

**Benchmark results**:
The scoring server's feedback on a submission — overall score, correct/total, timestamp, and message. The server does not return per-Question or per-Level correctness.
_Avoid_: grade, report
